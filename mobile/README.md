# Mom's Cloud Kitchen — Mobile

Expo SDK 58 + TypeScript + Expo Router MVP for customers and kitchen admin.

## Run

```bash
# Terminal 1 — API
cd ../backend && npm run start:dev

# Terminal 2 — App
npm install
npx expo start
```

Set `EXPO_PUBLIC_API_URL` if needed (default `http://localhost:3000`).  
Android emulator: `http://10.0.2.2:3000`.
